# المراجع الفقهية

يحتوي هذا المجلد على المراجع الفقهية التي استُخدمت في إعداد مشروع **KPA (research/بحث ) للوضوء**.

تمت إعادة تنظيم المحتوى إلى ملفات **Markdown** لتسهيل:

- الرجوع إلى الأحكام الفقهية.
- توثيق الأدلة الشرعية.
- بناء مفتاح الإجابات (Answer Key).
- ربط أسئلة الاستبيان بالأدلة والمراجع.
- مراجعة المحتوى وتحديثه باستخدام Git وGitHub.

> **تنبيه:** المحتوى الموجود في هذا المجلد هو إعادة تنظيم للمادة العلمية الواردة في المراجع الأصلية، مع الحفاظ على الإشارة إلى المصدر في نهاية كل ملف.
